Meridian IT Alerts: SMS Terms and Conditions

Last updated: November 23, 2026

1. Program

“Meridian IT Alerts” is a text message program run by Meridian Worldwide Transportation Group (“Meridian”).

2. What we send

Automated alerts about the status of Meridian’s servers and business applications. Examples: an application that has stopped responding, a server drive that is running low on space, or a failed software deployment. We also send a message when the problem is resolved.

The program is for Meridian employees and IT contractors who have agreed to receive these alerts. It is not offered to customers or the public, and it carries no marketing.

To join, a person completes and signs the Meridian IT Alerts consent form and returns it to the Meridian IT department. Nobody is added without a signed form.

3. Message frequency

Message frequency varies with system events.

4. Cost

Message and data rates may apply. Meridian does not charge for these messages.

5. How to stop

Reply STOP to any message. You will receive one message confirming that you have been removed, and no further alerts. Reply START to rejoin.

6. Help

Reply HELP to any message, or email admin@meridianww.com.

7. Carriers

Mobile carriers are not liable for delayed or undelivered messages.

8. Privacy

See the Meridian IT Alerts Privacy Policy.

9. Changes

We may update these terms. The date at the top of this page shows the latest version.
